# Перепрошивка имплантов — 0.1.0, тестовая версия RU/EN

Требуются Cyber Engine Tweaks, redscript и Codeware. Разрабатывается для установленной сборки Cyberpunk 2077 2.5.

Подойди к продавцу скриптов и посмотри на него с расстояния до 3,2 м. В списке взаимодействий появится «Перепрошивка имплантов». Выбери её обычными клавишами диалога. Откроется пошаговое игровое окно: карточка установленного импланта с иконкой → существующий бонус → значение и цена. По умолчанию выбранный бонус усиливается; замена его типа открывается отдельной кнопкой. В каталоге доступны поиск и категории. Обычный максимум и предел разгона показаны до ввода; цена пересчитывается автоматически, есть кнопки +/− и готовые значения максимума.

Поддерживаются 36 штатных дополнительных характеристик. Импланты без StatsShard, включая обычные операционные системы, не показываются. Число бонусов сохраняется; одинаковые бонусы запрещены. Изменение основного свойства импланта не предусмотрено.

Предел берётся из штатного пула характеристик и рассчитывается на временном образце с качеством выбранного импланта и текущими усилениями персонажа. Разгон разрешён до 120% этого предела.

Оплата — деньги **и** компоненты скриптов. Обе суммы и доступные запасы показаны отдельными карточками с игровыми иконками; при нехватке любого ресурса подтверждение блокируется. За T1 используются компоненты T2: отдельного штатного компонента скриптов T1 в прочитанных данных не найдено. Для T5, T5+ и T5++ — компоненты T5.

Цена сначала рассчитывается в условных единицах: база по качеству 15/30/60/90/120, плюс 5 за операцию. До обычного максимума тариф растёт квадратично. 110% стоит втрое, 120% — в восемь раз больше базового тарифа. Доплата за увеличение того же бонуса считается как разница тарифов; уменьшение не возвращает оплату. T5+ и T5++ имеют надбавки 15% и 35%.

Согласованная денежная часть — 180 эдди за условную единицу. Расход компонентов уменьшен в 10 раз и округляется вверх. Например, тариф 725 означает **73 компонента + 130 500 эдди**. Денежная сумма не вычисляется из уже округлённого количества компонентов.

Язык выбирается автоматически по настройке языка текста игры: русский интерфейс для русского, английский для английского. Локализованы диалог услуги, весь интерфейс, сообщения и 36 характеристик. Названия имплантов берутся из локализации игры. После смены языка закрой и заново открой услугу.

## Прошивки и сохранения

Прошивки создаются отдельно для каждой операции и не меняют глобальные записи имплантов. Их определения сохраняются в `bin/x64/plugins/cyber_engine_tweaks/mods/CyberwareReflash/profiles.json`; резерв — `profiles.json.bak`.

**Сохраняй эти файлы вместе с игровыми сейвами.** Сейв с перепрошитым имплантом зависит от мода и определений прошивок. Перед удалением мода вернись к сохранению до перепрошивки. Автоматического удаления мода с восстановлением всех исходных бонусов пока нет.

До операции создаётся временный образец и проверяются значения. Перед заменой оба платежа проверяются повторно и резервируются; при отказе замены код возвращает их. После замены проводится повторная проверка бонусов; при несовпадении код пытается вернуть прежнюю часть. Это не заменяет проверку поведения в игре.

## Проверки

- 36 характеристик извлечены из базы установленной игры.
- Изолированная компиляция redscript и проверка синтаксиса Lua пройдены.
- Совместная компиляция с 1214 файлами текущей сборки пройдена.
- Диалог продавца и открытие предыдущего интерфейса подтверждены в игре.
- Новая версия интерфейса проходит компиляцию с полной сборкой. Реальный Lua-код расчёта проверен в LuaJIT на числах с точкой/запятой, пределе разгона, стоимости по качеству, недостатке ресурсов, одинаковом значении и запрете дубликатов. Игровые API в этой проверке заменены тестовыми данными.
- Отображение пошагового интерфейса и ненулевых пределов подтверждено в игре до добавления новой оплаты.
- LuaJIT-проверки подтверждают раздельную цену, блокировку при нехватке любого ресурса, английские названия 36 характеристик и сообщения. Игровые API в этих проверках заменены тестовыми данными.
- Новые карточки оплаты, автоматический выбор языка, фактические эффекты, списание/возврат ресурсов и загрузка сохранения требуют проверки в игре.

Интерфейс использует Codeware UI и изученные учебные примеры psiberx (Ink Playground, MIT). Авторство Codeware и учебного проекта — Pavel Siberx. Библиотека interactionUI.lua сторонних модов в пакет не включена.
